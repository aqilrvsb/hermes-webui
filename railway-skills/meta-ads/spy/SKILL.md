# Meta Ads — Competitor Spy
Use the `zernio` (Meta/FB ads tools: ads_*, ad_campaigns_*, ad_audiences_*) MCP tools (and web/Ad Library search) to gather competitor ads.
1. Ask for the competitor page name(s) / domain / niche if not given.
2. Query the Meta Ad Library for their currently-running ads.
3. For each ad capture: hook (first line), angle, offer, format (image/video/carousel), CTA, and how long it has run (longevity = winner signal).
4. Group by angle and rank by estimated longevity/spend signals.
5. Output a table + 3 "steal-worthy" patterns to test, mapped to our offer.
