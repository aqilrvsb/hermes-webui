# Landing & Funnel pages (website-sales)

The page is half the conversion (Nick, Jordan, Tiana). The ad gets the click; the page makes the sale. Match
the page to the ad's **awareness stage** and keep the hook continuous ad → page → checkout.

## Page type by awareness
- **Unaware** → **advertorial / quiz** (educate first, no hard sell). PeningLab quiz: "Berapa banyak masa kau
  buang shoot video?"; PeningBot: "Berapa RM hilang sebab lambat reply?" (the cost calculator IS a quiz).
- **Problem-aware** → **listicle (us-vs-them)** — "5 sebab usahawan tukar ke PeningBot" / "5 sebab seller
  TikTok Shop guna PeningLab". Each point = us vs the painful alternative.
- **Product/most-aware** → straight to the **product/pricing page** + offer.

## Winning formats (keep dead-simple)
- **Listicle** and **quiz funnel** convert best (Nick). White background, black text, one idea per scroll.
- PeningBot site beats: pain mockup (47 unread WhatsApps) → **cost calculator** (slider → "RM5,400/bulan
  hilang") → transformation (tired vs relaxed split) → testimonials → "Mula Sekarang" → CHIP.
- PeningLab: hero "10 video / 3 minit" → 4-card pricing (Pro = BEST SELLER) → before/after (RM500 vs RM4) →
  proof → Subscribe → CHIP.

## Congruence rules (the conversion multiplier)
- The page **headline = the ad hook continued** (same angle, same words). Mismatch = the leak (Nick: "ad opens
  a curiosity the page never mentions" kills CR).
- One CTA repeated; CTA wording continuous ad→page→checkout ("Mula sekarang" / "Subscribe Pro").
- Proof near the CTA (specific numbers, real testimonials, founder).

## Output
This agent is advisory (pages live on peningbot.com / peninglab.com, owned by the dev). Produce a per-angle
page-congruence plan + concrete copy/structure recommendations → `_shared/funnel_<brand>.json` for the Ad
Builder (which page each ad points to) + the owner. Flag any ad→page mismatch the CRO/Analyst detects.
