# Meta Ads — Deploy Campaign
Use the `zernio` (Meta/FB ads tools: ads_*, ad_campaigns_*, ad_audiences_*) MCP tools. ALWAYS confirm budget + audience before creating anything live; create PAUSED first.
1. Confirm: objective, daily/lifetime budget, audience (location/age/interests), placements, creative set.
2. Create campaign (objective) -> ad set (budget, audience, optimization, schedule) -> ads (creatives).
3. Create everything in PAUSED status; show the full tree + estimated reach for review.
4. Only set ACTIVE after explicit user approval.
