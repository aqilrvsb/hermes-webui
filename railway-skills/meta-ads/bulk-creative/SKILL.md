# Meta Ads — Bulk Creative
1. Take the product/offer brief (or a proven winning ad) + target persona.
2. Generate variations across distinct angles: pain, desire, social proof, urgency, curiosity, authority.
3. For each: primary_text (<=125 chars hook-first), headline (<=40), description (<=30).
4. Default to 50 variations unless asked otherwise; dedupe near-identical lines.
5. Output as a CSV-ready table (angle, primary_text, headline, description) for upload or for `meta-deploy-ads`.
