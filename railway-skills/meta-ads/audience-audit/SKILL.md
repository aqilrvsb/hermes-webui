# Meta Ads — Audience Audit
1. List active audiences/ad sets with their targeting + size.
2. Identify likely overlaps (shared interests/lookalikes/geos) causing internal auction competition.
3. Recommend consolidation/exclusions; estimate saturation (frequency vs audience size).
4. Output an overlap matrix + consolidation plan.
