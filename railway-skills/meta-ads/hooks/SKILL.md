# Meta Ads — Hooks
1. Take offer + audience + main pain/desire.
2. Generate 50+ hooks across patterns: question, bold claim, callout, story-open, stat, contrarian, before/after, FOMO.
3. Keep each <=125 chars, native and non-spammy (avoid policy-risky claims).
4. Output ranked by predicted stopping power; mark top 10 to test.
