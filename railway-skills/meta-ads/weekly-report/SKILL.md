# Meta Ads — Weekly Report
1. Pull account + per-campaign insights for the last 7 days vs the prior 7.
2. Summarize: spend, results, CPA, ROAS, CTR, CPM with week-over-week deltas.
3. Highlight top 3 and bottom 3 ads, fatigue/bleed flags, and budget pacing.
4. End with 3-5 concrete next actions. Format clean for sharing (and Slack if SLACK_WEBHOOK_URL is set).
