Use these rules for every decision. (Ben Heath = setup/creative/targeting fundamentals;

## Antonio Ventre 2026 — advanced scaling (after $10M+ spent)
- **Judge ads by INCREMENTALITY, not reported ROAS.** A high front-end ROAS ad can be fake (purchases from existing customers). Use Breakdown → audience segment (judge by NEW-customer purchases) + the **incremental attribution** column. Run/learn on 7-day-click (more data) but **kill/scale on incremental**.
- **Stop the test-vs-scale split → consolidate into ONE CBO / one ad set** with many creatives (he runs 30–100 in one ad set). Duplicating campaigns/creatives causes audience overlap (bidding on the same people) + splits learning. One case: switching to single-CBO raised ROAS ~94% at same spend.
- **Meta optimizes the winning SEQUENCE, not single ads** → never turn off the high-spend / low-ROAS top-funnel ad; it's the incremental "heavy lifter" feeding your bottom-funnel winners. Killing it breaks the sequence.
- **Frequency discipline:** scale only winners with high ROAS AND low frequency (< ~1.7–1.8); kill high-frequency/low-ROAS ads.
- **Funnel mix by awareness:** deliberately balance top/mid/bottom (≈50/30/20). Statics skew mid/bottom (ceiling ~$10–30K/mo); add low-frequency top-funnel (problem-aware, no product shown → drive to listicle/advertorial/quiz) to lower bottom-funnel frequency and unlock scale. Convert winning static angles into VIDEO to scale.
- **Bid cap = the profit/scaling lever:** cap = AOV ÷ target ROAS; run a separate bid-cap campaign of proven winners (consistently below target CPA + top-3 spender). Tune in 5% steps within ±20%; it spends more on high-demand days. (Adapt for lead-gen: cap = lead-value ÷ target.)
- **Creative quality > volume:** net-new "trendsetting" concepts (research Pinterest/Reddit, make the VISUAL match the angle) beat copied/AI-recycled ads (already-saturated audiences, short lifespan). Use AI only to iterate proven winners; the visual must show the avatar in the pain or the transformation.
- **Whole system:** offer + landing page + content. Match each ad angle to a congruent landing page by awareness stage (unaware→advertorial/quiz, problem-aware→listicle, product-aware→PDP). Raise AOV with bundles/subscriptions + bonus-stacking (not bigger discounts).

## Ben Heath 2026 (synthesized from 26 videos)

## Structure — CONSOLIDATE
- One campaign + one ad set per product/pixel; many DIVERSE ads inside (15–20).
- Stop separating cold vs warm / TOFU-MOFU-BOFU — custom audiences are now "suggestions",
  so a "cold" set spends on warm anyway. Put founder/demo/testimonial ads in ONE ad set; Meta auto-sequences.
- Split into separate campaigns only by product *range* (PeningBot vs PeningLab), not by minor variation.
- Never duplicate a campaign to run copies (auction overlap).

## Creative = the #1 lever (see skills/ANDROMEDA.md)
- 15–20 distinct entities per ad set; hook (first 3s) is the biggest lever; recombine winning hook+body.
- Partnership ads via Creator Marketplace = cheat code (higher hook rate). Use real faces.

## Testing — big things first
Offer → Angle → Style → Hook → minor copy. Offer is #1 (most "no sales" = offer problem).
One angle per ad. Expect most tests to fail; one winner pays for the rest.

## Optimization & scaling
- Learning phase needs ~50 conv/week → consolidate or optimize a higher-funnel event if you can't hit it.
- Don't edit an ad set >1×/7 days.
- **Maximize VALUE of conversions** (not count) when basket/lead values vary.
- Scale in STEPS (bigger % at low budget, smaller % high; wait 5–7 days) to find the ROAS ceiling.
  Or automated rule: +3%/day when cost/result < target (daily budgets; window = last 3/7/14 days, never 37-mo).

## Attribution (2026)
Click-through now needs a real LINK click; old social-click conversions moved to "Engage-Through".
Video ads show the biggest reported drop — check back-end data, don't panic.

## Targeting that still matters
Broad + Value Rules (bid more for your most valuable segment). Detailed interests = suggestions only.
Only LOCATION is a hard constraint worth testing.

## Offer & funnel
Win on cheap/free tripwire OR high-ticket (avoid mid-range). **WhatsApp click-to-message funnels**
are cheap + preferred in MY — perfect for PeningBot/PeningLab. Pay more per conversion than rivals (work back from LTV).

## Spy
Ads Library: location = where ads SHOW; view inactive ads; **sort by Impressions** (longevity alone is
misleading post-Andromeda — high impressions = Meta is actually spending). Model smaller competitors you can copy.
