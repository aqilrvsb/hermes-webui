# Offer Design (the #1 lever)

Every elite source: fix the OFFER first. The offer = the perceived value the prospect gets for the price, not
the product. Use the brand brief in `_products/` + spy intel.

## Hormozi value equation
Perceived value = **(Dream outcome × Perceived likelihood of success) ÷ (Time delay × Effort & sacrifice).**
Increase the top (bigger dream, more proof), shrink the bottom (faster result, less effort). A "5-minit setup"
(PeningBot) or "10 video / 3 minit" (PeningLab) directly attacks time + effort — lean on these.

## The value stack (frame the subscription as a bundle)
List everything included with a RM value, so the price feels like a steal:
- **PeningBot Starter (RM35/mo):** auto-reply 24/7 (vs admin RM3,000) + closing notifications + sequences +
  playground + (add) hourly ads reporting RM12/slot. Anchor: "vs hire admin RM2,500–4,000/bulan".
- **PeningLab Pro (RM100/mo, BEST SELLER):** ~125 videos + 250 images + all tools + MCP + auto-scrape. Anchor:
  "vs RM300–500 per UGC video" → "RM100 = ~250 video, so <RM0.40 sebijik".

## Price framing & anchoring
- **Anchor against the expensive alternative** (admin salary / per-video cost), then show your price as a
  fraction. "Bayar 1 hari je dah cover sebulan" (PeningBot). "5 affiliate sale dah cover" (PeningLab).
- **Tier strategy:** make the target tier the obvious value pick. PeningLab Pro carries the BEST SELLER ribbon
  + 50%-back-in-credits framing — push it. PeningBot: Starter as the low-friction entry, upsell Pro/Premium later.
- Be transparent about pass-through costs (OpenRouter credits / WhatsApp API) — hiding them kills trust.

## Risk reversal (lower perceived risk = higher conversion)
- PeningBot: **7-day refund** (technical issues), cancel anytime, no contract. Lead with it for skeptics.
- PeningLab: case-by-case refund via WhatsApp VIP; "try Starter RM35, tak puas refund."
- **NO free trial** for either (don't invent one) — substitute the low-price entry tier + refund as the risk-reducer.

## Offer enhancers (not the offer itself)
Festive promos (Raya/CNY/payday/11.11), launch discounts ("Promo Pro RM100 — bukan RM300"), scarcity
("Tinggal 17 slot"), bonus templates/prompts. Use to boost a solid offer, never to rescue a weak one.

## Testing the offer
Offer is tested BEFORE angle/creative (see `testing-scaling` order). Signals an offer problem: traffic +
clicks but **no checkouts/purchases** despite good hook/CTR → change the offer (speed up result, add value,
reduce risk, clarify), not the creative. Output per brand → `_shared/offer_<brand>.json` for the Strategist + Copywriter.
