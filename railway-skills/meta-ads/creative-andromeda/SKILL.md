# Creative for the Andromeda era (2026)

Meta's **Andromeda** AI selects which ad to show each user from your pool. It **collapses near-identical
creatives into one "entity"** (only one gets spend) and optimizes the winning **sequence** of ads, not single
ads. So creative is the #1 lever — and *diversity* matters more than raw count.

## Diversity > volume (but you still need volume)
- **Diversity, not variations.** CT: "creative diversity ≠ creative volume." A few *meaningfully different*
  ads doing different jobs (problem ad / proof ad / reminder ad) beats 30 colour-swaps. Tiana: the VISUAL
  decides who Meta serves it to.
- **But real volume is required to scale** (Sam, Jordan): big brands run hundreds–thousands of active ads.
  Reconcile: each ad must be a **distinct entity** (different concept + copy), then add volume of distinct entities.
- **Volume by spend tier (Jordan):** ~$1k/day → ≥5 concepts/wk; $3–5k/day → 7–8/wk; >$5k/day → 15–20/wk.
  Nick: 50 new creatives/client/wk regardless of performance. Media Ninja: 20–40+/wk at $100k+/mo. Floor: 2/wk.

## Ad-set structure: the unit of testing
- **Ad set = ONE idea/avatar/angle** (see `meta-ads-playbook-2026` law 4). New idea → new ad set in the same CBO.
- **The 3-ads-per-set rule (Nick, CT's "322"):** each ad set = 3 ads that are **identical except the first
  3–5s VISUAL HOOK** (same body, same primary text, same offer). This isolates the hook as the only variable.
  - CT's **322 ad** = 3 creatives × 2 primary texts × 2 headlines = 12 combos, all ONE format (3 videos OR 3
    images, never mixed — Meta compares like-for-like). It self-optimizes; pooled signal compounds.
  - Max ~3 creatives per ad; want more → build another 322. Account-level: ~5–8 strong ads/concepts in the
    "control", prune the worst.
- **Iteration ≠ small tweak.** Andromeda groups headline/colour swaps as the SAME entity. A real iteration is
  a **new creative on the same angle** (new hook, reshoot, new background, new POV). (Jordan, CT, Sam)

## Winner signals (how to know in 24–72h)
- **Top-5 spend within 24–48h = winner (Jordan).** If Meta gives a creative little/no spend, it was never
  going to work — **discard, don't force spend** (CT: every new ad starts at EAR 0 and looks great for 2 days
  then tanks; forcing spend is self-sabotage).
- **Hook rate** = 3-sec video plays ÷ impressions. Good ≈ **30%+** (weak ≈ 7–9%). Low hook rate → fix ONLY the
  first 3s (swap the hook, keep the body). (Jordan, CT)
- **Hold rate** at 25/50/75/100%: want **≥40%** still watching at the relevant checkpoint. Strong hold =
  angle/audience match → go deeper; medium → restructure but keep the angle. (Jordan)
- **Win ratio** = % of produced ads that become scalable winners. 10 made, 1 wins = 10%. **Target 15–20%**,
  and KEEP it as you scale volume (the trap: volume that drops win-ratio nets fewer winners). (Jordan)
- **"Impact":** a true winner pulls overall spend up AND lowers blended CPA within ~24h. (Nick)

## Format & editing rules
- **Mix formats** (video bulk + statics). Video = best hook/attention + scale; statics = efficiency/retarget
  ("follow people around" after the video plants the idea — CT). Make **image versions of winning videos**.
- **Editing:** scene change every **2–3s** (1s for young, slower for older); **native-style captions**
  (CapCut/IG look, "like a friend posted"); talking-head ≈ **50/50 A-roll / B-roll**. (Jordan, Nick)
- **B-roll kills hidden objections** without copy: show the product/flow held, used, in its real setting —
  pre-answers "is it real / fast / legit?" (Tiana). For SaaS: show the product working live — the bot auto-replying / the 10-video batch generating.
- **AI-look is now an objection.** Mix in some real footage / real local creators; don't ship obviously-fake
  AI UGC at scale (Tiana, Andy, Jordan). Use AI to find the winning angle cheaply, then have a real creator scale it.

## The creative-learnings ritual (the relaunch engine — Nick)
After every 7-day test, the strategist sets a **15-minute timer and stares at each creative — winners AND
losers** — logging what went right/wrong/improvable (idea, hypothesis, creative learnings). Relaunch tweaked
versions of winners. "Only 5–10% of people do this" and it's the #1 source of new winners.

## Partnership / UGC ads = the cheat code
Run winning content through a creator's or a niche "news" page (Meta forces **Partnership ads** now; brand
name shows — no perf difference vs old whitelisting). Lowers CAC, spreads risk, feels native. Source via Meta
**Creator Marketplace**. Pay ~10% of budget to a creator that makes the campaign ~40% better (Heath, Jordan).
